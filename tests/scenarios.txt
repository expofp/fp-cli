# fp's scenario table: one row per scenario, read by tests/run.sh (fp under /bin/sh and dash)
# and tests/run.ps1 (fp.ps1 under pwsh). Columns are separated by "|":
#
#   name | setup | folder | arguments | exit code | expectations
#
# Each row runs in a fresh workspace $W with its own $HOME ($W/home), stdin not a terminal, and a
# PATH holding only fpecho (prints "fpecho: <args>"), git and the few tools fp uses.
# Placeholders: $W, $HOME, $SHA1 and $SHA2 (main's and next's commits in the git fixture).
#
# setup, steps separated by " ; ":
#   repo <dir>          makes <dir> a git repo's root (a .git folder in it)
#   dir <dir>           makes <dir>
#   target <dir>        makes a target: <dir>/bin/fp and bin/fp.ps1 print "<name of dir>: <args>",
#                       and with the arguments "exit <n>" exit with <n>
#   write <file> <text> writes the text and a newline (no text: an empty file)
#   remove <file>       removes the file
#   fp <dir> <args>     runs fp in <dir>; it must succeed
#   commit              moves the fixture's main to $SHA2
#   nogit               the row's run (not setup) has no git on the PATH
# The git fixture is git:example.test/acme/tool: main at $SHA1 whose bin/fp prints "git v1: <args>",
# next at $SHA2 printing "git v2: <args>".
#
# folder: where the row runs, relative to $W. arguments: split on spaces.
# expectations, separated by " ; ":
#   out <text>          the output (stdout and stderr) contains the text
#   noout <text>        the output does not contain it
#   first <file> <text> the file's first line is the text
#   has <file> <text>   the file has a line that is the text
#   nofile <file>       the file does not exist
